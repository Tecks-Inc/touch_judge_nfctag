# touch_judge_nfctag.py の使い方

このドキュメントでは、Pythonスクリプト`touch_judge_nfctag.py`を使用して、
PC/SC 対応カードリーダーでNFCタグ・ICカード（Suica、FeliCa、Type A/B カードなど）を読み取る方法をまとめます。

---

## 1. 必要な環境

### 動作環境
- Python 3.x が動作し、`pip` コマンドが利用可能な環境（Windows / macOS / Linux など）
- OS側に PC/SC ドライバ、および PC/SC ミドルウェア（Linuxの場合は `pcscd` など）が導入され、正常に動作していること

※ 各OSにおけるPC/SC環境の構築や、ライブラリのインストール時に発生するコンパイルエラー等の環境依存の問題については、ユーザーご自身での解決をお願いいたします。

### 必要ライブラリ
インストールコマンド:
```bash
python -m pip install pyscard
```
*(※ 環境に応じて `python3` を使用してください)*

### 必要な機器
- PC/SC対応カードリーダー
- NFCタグ・物理ICカード（Suica、FeliCaカード、クレジットカード、マイナンバーカードなど）  
※ スマートフォンのモバイル系カード（モバイルSuica/モバイルPASMO など）は、リーダーやスクリプトの仕様上、通信タイミングが合わず正常に検知できない可能性が高いため非対応としています。

---

## 2. スクリプトの起動方法

ターミナル（PowerShell/Terminal/bash など）で以下を実行します。

```bash
python touch_judge_nfctag.py
# または
python3 touch_judge_nfctag.py
```

### 💡 Raspberry Pi などの Linux 環境で動作しない場合
お使いの環境（Raspberry Piなど）によっては、一般ユーザー権限ではカードリーダーへのアクセス権限が足らず、認識されない場合があります。その場合は、以下のように **`sudo`（管理者権限）をつけて実行** してください。

```bash
sudo python3 touch_judge_nfctag.py
```

起動すると、次のような案内が表示されます。

```
使用するリーダー: <リーダー名>
--------------------------------------------------
 NFCタグ・ICカード（Suica、クレジットカード、マイナンバーカード等）をかざしてください。
 ※ スマートフォン（モバイルSuica等）には対応していません。
 ※ 終了するには Ctrl + C を押してください。
--------------------------------------------------
```

---

## 3. カードをかざしたときの挙動

カードをリーダーにかざすと、以下の情報が自動的に表示されます。

- ATR（カードの応答情報）
- カード規格（TypeA/TypeB/FeliCa）
- UIDまたはIDm（カード固有番号）

例:
```
◆ カードを検知しました ◆
  [ATR値]   : 3B 8F 80 01 80 ...
  [規格] : ISO/IEC 14443 Type A
  [UID番号] : 044C90F2935C80
--------------------------------------------------
```

カードを離すと次のメッセージが表示されます。

```
◆ カードが離れました。 ◆
```

---

## 4. 終了方法

プログラムを終了するには、ターミナルで`Ctrl + C`を押します。

---

## 5. トラブルシューティング

### カードリーダーが認識されない場合（エラーが表示される場合）
- USBケーブルの再接続、またはOS側のカードリーダー用ドライバが正しくインストールされているかご確認ください。
- 一部カードはUID取得コマンド（`FF CA 00 00 00`）に非対応のため、公的ICカードなどはATRのみ取得可能です。

---

## 6. 補足

このスクリプトは、カードを置いた瞬間と離した瞬間を検知し、
連続読み取りを防ぐためのガード処理が組み込まれています。

PC/SCカードリーダーを使った簡易的なカード種別判定ツールとして利用できます。
